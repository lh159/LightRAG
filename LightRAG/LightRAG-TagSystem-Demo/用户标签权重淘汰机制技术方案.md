# 用户标签权重淘汰机制技术方案

## 1. 方案概述

### 1.1 背景与目标
在对话流中，用户的兴趣、情感状态和行为模式会随时间动态变化。为了保持用户画像的准确性和时效性，需要建立一套完善的标签权重淘汰机制，确保用户画像能够反映用户的最新特征。

### 1.2 设计原则
- **时效性**：及时淘汰过时的标签，保持画像新鲜度
- **准确性**：基于多维度指标进行淘汰决策
- **稳定性**：避免频繁的标签变动，保持画像稳定性
- **可解释性**：淘汰决策过程透明，便于调试和优化

## 2. 淘汰机制架构

### 2.1 核心组件
```
标签淘汰机制
├── 权重衰减模块 (Weight Decay Module)
├── 冲突检测模块 (Conflict Detection Module)
├── 活跃度评估模块 (Activity Assessment Module)
├── 淘汰决策模块 (Elimination Decision Module)
└── 淘汰执行模块 (Elimination Execution Module)
```

### 2.2 数据流
```
用户对话 → 标签提取 → 权重计算 → 淘汰评估 → 淘汰执行 → 画像更新
```

## 3. 淘汰策略设计

### 3.1 多维度淘汰指标

#### 3.1.1 时间维度
- **最后强化时间**：标签最后一次被强化的时间
- **衰减周期**：标签权重衰减的时间周期
- **淘汰阈值**：超过阈值时间未强化的标签将被淘汰

#### 3.1.2 权重维度
- **当前权重**：标签的当前权重值
- **权重趋势**：标签权重的变化趋势
- **权重阈值**：低于阈值的标签将被淘汰

#### 3.1.3 活跃度维度
- **触发频率**：标签在对话中的触发频率
- **证据强度**：支持标签的证据强度
- **用户反馈**：用户对标签的反馈（显式或隐式）

#### 3.1.4 冲突维度
- **标签冲突**：与高置信度新标签的冲突程度
- **行为矛盾**：与用户当前行为的矛盾程度
- **上下文不符**：与当前对话上下文的不符程度

### 3.2 淘汰策略分类

#### 3.2.1 渐进式淘汰
- **适用场景**：权重逐渐降低的标签
- **淘汰方式**：逐步降低权重，最终淘汰
- **优势**：平滑过渡，避免突变

#### 3.2.2 冲突式淘汰
- **适用场景**：与新标签存在明显冲突的标签
- **淘汰方式**：立即淘汰冲突标签
- **优势**：快速响应，保持一致性

#### 3.2.3 活跃度淘汰
- **适用场景**：长期未被触发的标签
- **淘汰方式**：基于活跃度阈值淘汰
- **优势**：保持画像简洁性

## 4. 技术实现方案

### 4.1 权重衰减算法

```python
def calculate_decay_factor(tag: Dict, current_time: datetime) -> float:
    """
    计算标签衰减因子
    
    Args:
        tag: 标签信息
        current_time: 当前时间
    
    Returns:
        衰减因子 (0.0-1.0)
    """
    last_reinforced = datetime.fromisoformat(tag["last_reinforced"])
    days_since_reinforced = (current_time - last_reinforced).days
    
    # 基础衰减率
    base_decay_rate = tag.get("decay_rate", 0.1)
    
    # 根据标签类型调整衰减率
    tag_type = tag.get("tag_type", "general")
    if tag_type == "emotional":
        decay_rate = base_decay_rate * 1.5  # 情感标签衰减更快
    elif tag_type == "interest":
        decay_rate = base_decay_rate * 0.8  # 兴趣标签衰减较慢
    else:
        decay_rate = base_decay_rate
    
    # 计算衰减因子
    decay_factor = max(0.05, 1.0 - (days_since_reinforced * decay_rate / 30))
    
    return decay_factor
```

### 4.2 冲突检测算法

```python
def detect_tag_conflicts(existing_tags: List[Dict], new_tags: List[TagInfo]) -> List[Dict]:
    """
    检测标签冲突
    
    Args:
        existing_tags: 现有标签列表
        new_tags: 新提取的标签列表
    
    Returns:
        冲突信息列表
    """
    conflicts = []
    
    for new_tag in new_tags:
        for existing_tag in existing_tags:
            # 检查语义冲突
            if is_semantic_conflict(existing_tag, new_tag):
                conflict_score = calculate_conflict_score(existing_tag, new_tag)
                if conflict_score > CONFLICT_THRESHOLD:
                    conflicts.append({
                        "existing_tag": existing_tag,
                        "new_tag": new_tag,
                        "conflict_score": conflict_score,
                        "conflict_type": "semantic"
                    })
            
            # 检查行为冲突
            if is_behavioral_conflict(existing_tag, new_tag):
                conflicts.append({
                    "existing_tag": existing_tag,
                    "new_tag": new_tag,
                    "conflict_score": 1.0,
                    "conflict_type": "behavioral"
                })
    
    return conflicts
```

### 4.3 活跃度评估算法

```python
def assess_tag_activity(tag: Dict, user_activity_data: Dict) -> float:
    """
    评估标签活跃度
    
    Args:
        tag: 标签信息
        user_activity_data: 用户活动数据
    
    Returns:
        活跃度分数 (0.0-1.0)
    """
    # 触发频率评分
    trigger_frequency = calculate_trigger_frequency(tag, user_activity_data)
    
    # 证据强度评分
    evidence_strength = tag.get("avg_confidence", 0.0)
    
    # 时间衰减评分
    time_decay = calculate_time_decay_score(tag)
    
    # 综合活跃度分数
    activity_score = (
        trigger_frequency * 0.4 +
        evidence_strength * 0.3 +
        time_decay * 0.3
    )
    
    return activity_score
```

### 4.4 淘汰决策算法

```python
def make_elimination_decision(tag: Dict, context: Dict) -> Dict:
    """
    做出淘汰决策
    
    Args:
        tag: 标签信息
        context: 上下文信息
    
    Returns:
        淘汰决策
    """
    decision = {
        "should_eliminate": False,
        "elimination_type": None,
        "confidence": 0.0,
        "reason": ""
    }
    
    # 计算各项指标
    weight_score = tag.get("current_weight", 0.0)
    activity_score = assess_tag_activity(tag, context.get("user_activity", {}))
    conflict_score = context.get("conflict_score", 0.0)
    time_score = calculate_time_score(tag)
    
    # 综合决策
    elimination_score = (
        (1.0 - weight_score) * 0.3 +
        (1.0 - activity_score) * 0.3 +
        conflict_score * 0.2 +
        (1.0 - time_score) * 0.2
    )
    
    if elimination_score > ELIMINATION_THRESHOLD:
        decision["should_eliminate"] = True
        decision["confidence"] = elimination_score
        
        # 确定淘汰类型
        if conflict_score > 0.7:
            decision["elimination_type"] = "conflict"
            decision["reason"] = "与新标签存在严重冲突"
        elif weight_score < 0.2:
            decision["elimination_type"] = "weight"
            decision["reason"] = "权重过低"
        elif activity_score < 0.3:
            decision["elimination_type"] = "activity"
            decision["reason"] = "活跃度过低"
        else:
            decision["elimination_type"] = "comprehensive"
            decision["reason"] = "综合指标不达标"
    
    return decision
```
