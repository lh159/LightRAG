# 标签结构升级说明

## 概述

本次升级将原有的一级标签系统升级为二级标签系统，以支持更精细的用户画像分析。

## 新的标签结构

### 一级标签（3个主要维度）

#### 1. 基本人口统计学标签 (demographic_info)
- **年龄 (age)**: 年龄段特征（如青少年、中年、老年等）
- **性别 (gender)**: 性别相关的语言风格和话题偏好  
- **地域 (location)**: 地区文化、方言、生活习惯特征

#### 2. 兴趣爱好标签 (interests_hobbies)
- **娱乐爱好 (entertainment)**: 电影、音乐、游戏、阅读等娱乐相关
- **运动爱好 (sports)**: 体育运动、健身、户外活动等
- **学习与职业相关爱好 (learning_career)**: 专业技能、行业知识、学习兴趣等

#### 3. 情绪与情感状态标签 (emotional_state)
- **当前情绪状态 (current_mood)**: 高兴、悲伤、愤怒、焦虑等情绪
- **情感需求 (emotional_needs)**: 倾诉需求、鼓励支持、陪伴等情感诉求

### 1. 数据结构修改

#### TagInfo类更新
```python
@dataclass
class TagInfo:
    name: str
    confidence: float
    evidence: str
    category: str      # 一级标签类别
    subcategory: str   # 二级标签类别
```

## 使用方式

### 标签提取示例
```python
from core.tag_extractor import TagExtractor

extractor = TagExtractor("user_id")
tags = extractor.extract_tags_from_text("我是一个90后程序员，喜欢看电影")

# 返回结构:
# {
#   "demographic_info": [
#     TagInfo(name="90后", category="demographic_info", subcategory="age", ...)
#   ],
#   "interests_hobbies": [
#     TagInfo(name="电影爱好者", category="interests_hobbies", subcategory="entertainment", ...)
#   ]
# }
```

### 标签管理示例
```python
from core.tag_manager import TagManager

manager = TagManager("user_id")
result = manager.update_tags(extracted_tags)
```

## 优势

1. **更精细的分类**: 二级标签提供更细粒度的用户画像
2. **更好的组织**: 标签按功能域分组，便于管理和查询
3. **扩展性强**: 易于添加新的二级标签类别
4. **向后兼容**: 支持旧系统的平滑迁移

## 注意事项

1. 现有用户数据需要迁移到新结构
2. 前端界面需要相应调整以显示二级标签
3. 建议在生产环境部署前进行充分测试
4. 考虑为大量用户数据提供批量迁移工具
